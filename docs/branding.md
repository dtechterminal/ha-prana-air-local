# Brand images

`custom_components/prana_air_local/brand/` holds the images Home Assistant shows for
this integration (Home Assistant 2026.3 and newer serve them straight from that
folder, also when offline):

| File | Contents |
|---|---|
| `logo.png`, `logo@2x.png` | AQI wordmark, 128 and 256 px tall |
| `dark_logo.png`, `dark_logo@2x.png` | Wordmark with white letters for dark themes |
| `icon.png`, `icon@2x.png` | The multicolour "Q", 256 and 512 px square |

They are generated by `tools/make_brand.sh` from the files in `docs/brand/`, both
published on aqi.in: `aqi-logo.svg` (`/media/misc/aqi-logo.svg`, the site logo; the
small ® glyph is left out because it is set in a font) and `aqi-favicon.png` (the
site's favicon, `/media/favicons/favicon.png`, converted from WebP). AQI.in is not in
the [Home Assistant brands project](https://github.com/home-assistant/brands).

The AQI.in name and logo belong to their owner. They identify the compatible
device; this community integration is independent of AQI.in and Prana Air. Brand
artwork is not covered by this project's MIT code license.
